# ❤️ Heart Disease Prediction using KNN

A Machine Learning project that uses **K-Nearest Neighbors (KNN) Classification** to predict the presence of heart disease based on selected patient health and exercise-related attributes.

## 📌 Project Overview

This project focuses on building a classification model that predicts whether a patient is likely to have heart disease.

The model uses **KNN Classification** and **StandardScaler** for feature scaling. The trained model was then integrated into an interactive **Streamlit web application** where users can enter patient information and receive a prediction.

## 📊 Features Used

The model was trained using the following 9 features:

* `age` — Patient age
* `sex` — Patient sex
* `cp` — Chest pain type
* `thalach` — Maximum heart rate achieved
* `exang` — Exercise-induced angina
* `oldpeak` — ST-segment depression
* `slope` — Slope of the peak exercise ST segment
* `ca` — Number of major vessels
* `thal` — Thalassemia-related dataset feature

The target variable is:

```text
target
```

## 🤖 Model

**Algorithm:** K-Nearest Neighbors (KNN)

KNN classifies a new observation based on the observations that are closest to it in feature space.

Since KNN is distance-based, **feature scaling** is important. `StandardScaler` was used before making predictions.

## 🚀 Run the Project Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd heart-disease-prediction
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.

## 📦 Model Files

The trained model and scaler are stored using Python's `pickle` module:

The application loads these files and uses them for prediction without retraining the model.
